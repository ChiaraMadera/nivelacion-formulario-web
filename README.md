# Actividad de Nivelación – Formulario Web

> 📌 **Contexto:** Proyecto práctico desarrollado para el periodo de nivelación del curso **Full Stack** de la **Fundación CILSA**.

---

## 📋 Descripción

El proyecto consiste en el desarrollo de un formulario web interactivo de datos personales, enfocado en el uso correcto de **HTML5 semántico**, estilos con **CSS3** (incluyendo accesibilidad visual) y manipulación del DOM mediante **JavaScript**.

---

## 🚀 Funcionalidades y Pasos de Desarrollo

- **Estructura y semántica (Paso 1):** Creación del formulario con campos clave:
  - Nombre y Apellido (`text`)
  - Correo electrónico (`email`)
  - Fecha de nacimiento (`date`)
  - País de residencia (`select`)
  - Botón de envío y selectores de visualización
- **Modo Alto Contraste (Paso 2):** Implementación de una paleta accesible pensada para optimizar la legibilidad (fondos oscuros, tipografía clara y buen contraste de elementos).
- **Validaciones nativas (Paso 3):** Uso de atributos de HTML5 (`required`, tipos de entrada y restricciones de formato) para validar los datos directamente desde el navegador sin dependencias externas.
- **Interactividad (Paso 4):**
  - Validación antes del envío de datos.
  - Alternancia dinámica entre tema estándar y tema de alto contraste mediante botones dedicados.

---

## 🛠️ Tecnologías

- **HTML5:** Estructura semántica, accesibilidad y atributos nativos de validación.
- **CSS3:** Maquetado, diseño adaptable y esquemas de contraste.
- **JavaScript (Vanilla):** Gestión de eventos del DOM y cambio de estilos dinámico.
